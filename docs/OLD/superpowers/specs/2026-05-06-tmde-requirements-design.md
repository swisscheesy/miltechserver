# TMDE Requirements Feature Design

**Date:** 2026-05-06
**Branch:** tmde
**Status:** Approved

## Overview

Expose the `tmde_requirements` table via two public (no auth) read-only REST endpoints. The table stores Test, Measurement, and Diagnostic Equipment (TMDE) calibration/service requirements keyed by NIIN.

---

Generated by Jet — do not modify.

| Column | Type | Notes |
|--------|------|-------|
| `niin` | `string` | Primary key — one row per NIIN |
| `qty_skot` | `*int32` | Nullable |
| `component` | `*string` | Nullable |
| `interval` | `*string` | Nullable |

Jet model: `.gen/miltech_ng/public/model/tmde_requirements.go`

## API Endpoints

Both endpoints are public, registered on `v1Route` (`/api/v1`).

### GET /api/v1/tmde/niin/:niin

Look up a single TMDE requirement by NIIN. NIIN is the primary key so at most one record is returned.

**Path param:** `niin` — trimmed and uppercased before query.

**Responses:**

| Condition | Status | Body |
|-----------|--------|------|
| Found | 200 | `StandardResponse{Data: model.TmdeRequirements}` |
| Blank NIIN | 400 | `{"error": "NIIN parameter is required"}` |
| Not found | 404 | `NoItemFoundResponseMessage()` |
| DB error | 500 | `InternalErrorResponseMessage()` |

**200 data shape:**
```json
{
  "niin": "012345678",
  "qty_skot": 4,
  "component": "SOME COMPONENT",
  "interval": "ANNUAL"
}
```

---

### GET /api/v1/tmde/requirements?page=1

Paginated list of all TMDE requirements. No filtering. 100 records per page.

**Query param:** `page` — integer, defaults to `1` if omitted.

**Responses:**

| Condition | Status | Body |
|-----------|--------|------|
| Success | 200 | `StandardResponse{Data: TmdePageResponse}` |
| Non-numeric or `< 1` page | 400 | `{"error": "Invalid page number"}` |
| No rows (empty table or beyond last page) | 404 | `NoItemFoundResponseMessage()` |
| DB error | 500 | `InternalErrorResponseMessage()` |

**200 data shape:**
```json
{
  "items": [...],
  "count": 100,
  "page": 1,
  "total_pages": 42,
  "is_last_page": false
}
```

## Data Flow

### NIIN Lookup
```
Handler.lookupByNIIN
  → validate: reject blank NIIN → 400
  → service.LookupByNIIN
      → normalize: TrimSpace + ToUpper
      → repository.GetByNIIN
          → Jet SELECT AllColumns WHERE niin = $1
          → ErrNotFound if no row returned
  → map errors → 404 / 500
  → 200 StandardResponse
```

### Paginated List
```
Handler.listAllPaginated
  → parse page param (default "1"), reject < 1 → 400
  → service.GetAllPaginated(page)
      → repository.GetAllPaginated(page)
          → Jet SELECT AllColumns LIMIT 100 OFFSET (page-1)*100
          → COUNT(*) query for total_pages
          → ErrNotFound if result set empty
  → map errors → 404 / 500
  → 200 StandardResponse
```

## Response Types

`TmdePageResponse` is defined in `api/tmde/response.go` (package-local, not added to `api/response/` since it is not shared):

```go
type TmdePageResponse struct {
    Items      []model.TmdeRequirements `json:"items"`
    Count      int                      `json:"count"`
    Page       int                      `json:"page"`
    TotalPages int                      `json:"total_pages"`
    IsLastPage bool                     `json:"is_last_page"`
}
```

## Error Handling

Sentinel errors in `api/tmde/errors.go`:

```go
var (
    ErrNotFound    = errors.New("no TMDE requirements found")
    ErrEmptyParam  = errors.New("required parameter is empty")
    ErrInvalidPage = errors.New("page number must be greater than 0")
)
```

Handler maps errors using `errors.Is`, consistent with `api/eic/route.go`.

## Testing

New package `tests/tmde/`:

**`main_test.go`**
- `TestMain` connects to `postgres://postgres:potato123@192.168.20.70/miltech_ng_test`
- Loads `.env` via `godotenv` (walks up directory tree)
- Fatals if `TEST_DATABASE_URL` is unset

**`handlers_test.go`** — test cases:
- Blank NIIN (`%20%20`) → 400
- Invalid page (`?page=bad`) → 400
- Zero page (`?page=0`) → 400
- Valid NIIN present in test DB → 200, correct shape
- NIIN not found → 404
- Page 1 of requirements list → 200, correct pagination shape
- Page beyond total → 404

All tests guard with `hasRelation(t, testDB, "tmde_requirements")` + `t.Skip()` if table is absent, so the suite is safe to run before the table exists in the test DB.
